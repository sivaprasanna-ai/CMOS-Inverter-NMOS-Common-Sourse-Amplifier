# CMOS-Inverter-NMOS-Common-Sourse-Amplifier

This repository contains transistor-level Analog VLSI designs
implemented and simulated using Xschem, Ngspice, and the SKY130 PDK.

## Designs

### 1. CMOS Inverter
- CMOS transistor-level schematic
- Xschem symbol creation
- Ngspice simulation
- Output waveform verification

### 2. NMOS Common-Source Amplifier
- SKY130 NMOS transistor
- DC bias analysis
- Transient analysis
- AC small-signal analysis
- Voltage gain and frequency-response analysis

## Tools
- Xschem
- Ngspice
- SKY130 PDK
